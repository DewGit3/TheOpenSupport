# TheOpenSupport (TOS)
A lightweight Python launcher for opening **websites and applications by name**.

## Features

-  Open websites by name
-  Launch applications by name
-  Add custom websites and applications without editing the source code

## Requirements
- Python 3.x

## Run
python main.py

## Project Structure


main.py
main_page.py
commands.py

main.py — application entry point

main_page.py — main interface

commands.py — commands and launcher logic

## Libraries
TOS uses only Python standard libraries:

- webbrowser
- os
- time
